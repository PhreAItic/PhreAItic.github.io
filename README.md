# PhreAItic

A live map and reliability page for machine-learning groundwater-level forecasts across France, published as a static site (GitHub Pages).

- `index.html` -- the map (English)
- `nappes_de_france_fr.html` -- the map (French)
- `trust_page.html` / `trust_page_fr.html` -- methodology and reliability notes

This repository contains only the built static site. The forecasting pipeline, models, and data-processing code are not published here.
